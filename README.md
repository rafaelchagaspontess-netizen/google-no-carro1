# Google no Carro

App Android com suporte ao Android Auto: pesquisa com sugestões do Google na tela do carro,
resumo em texto lido em voz alta e botão "Ir até lá" que abre a navegação.
No celular, abre o Google completo com atalhos para as pesquisas feitas no carro.

APK compilado automaticamente pelo GitHub Actions no branch `apk`.
